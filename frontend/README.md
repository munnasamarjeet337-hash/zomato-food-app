# Zomato Food App | Reels-Style Food Discovery 🍔🎥

A full-stack food delivery web application built using the MERN stack (MongoDB, Express.js, React, Node.js), featuring an interactive reels-style video feed for discovering food items, user authentication, and restaurant partner management.

## 🚀 Features
* **Reels-Style Video Feed:** Smooth vertical video scrolling experience to discover and explore food items visually.
* **Dual User Roles:** Separate registration and login workflows for regular **Users** and **Food Partners** (Restaurants).
* **Food Partner Dashboard:** Restaurant partners can easily upload new food items with videos and details.
* **Interactive Engagements:** Users can like and save their favorite food items for quick access.

## 🛠️ Tech Stack
* **Frontend:** React, Vite, CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB, Mongoose
* **Media Handling:** Multer / Cloudinary (for video and image uploads)
